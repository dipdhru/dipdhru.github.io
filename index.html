How I work

Every project follows the same loop.

A model is only as good as the evidence behind it. I build the evaluation before I trust the result, and ship it where people can try it.

01

Data

Clean, version and split it so the test set never leaks into training.

pandas · SQL · Open-Meteo · MedQuAD
02

Model

Start from a simple baseline, then earn every bit of added complexity.

scikit-learn · Keras · Prophet · e5 · LLMs
03

Evaluate

Held-out benchmarks, confidence intervals and failure cases, reported as measured.

rolling-origin · hit@k · bootstrap CI
04

Ship

Tested code, CI on every push, and a demo anyone can open.

pytest · GitHub Actions · Streamlit · Docker
